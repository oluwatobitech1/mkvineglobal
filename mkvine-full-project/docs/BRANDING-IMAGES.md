# Branding project images

Drop files into `public/work/<project>/`. Formats: png, jpg, webp, avif.

- `header.png` is the top image and the card cover.
- `footer.png` is the closing image.
- `contact.png` is shown just above the contact band.
- `01.png`, `02.png`, ... belong to the numbered list item below. Add more for the same item with `01-b.png`, `01-c.png` (anything after the number is free).
